# AI-Agriculture-Intelligent-Agent
An AI-powered agriculture support application featuring five specialized AI agents for crop recommendation, soil health analysis, smart irrigation, crop disease detection, and weather intelligence. Supports multilingual farming assistance using Gemini AI, React, Vite, Python FastAPI, and Open-Meteo API.
🌱 AI Agriculture Intelligence Agent

📌 Project Overview

The AI Agriculture Intelligence Agent is an AI-powered web application designed to support farmers in making smarter farming decisions. It integrates five specialized AI agents into a single platform, providing intelligent recommendations related to crops, soil health, irrigation, plant diseases, and weather conditions.

The application also provides multilingual farming assistance in English, Telugu, Hindi, and Tamil.

🚀 Key Features

1. Crop Recommendation – Provides crop suitability suggestions based on location and soil information.
2. Soil Health Analysis – Analyzes soil pH, NPK values, and moisture levels.
3. Smart Irrigation – Provides irrigation recommendations using farm details and weather conditions.
4. Crop Disease Detection – Analyzes uploaded leaf images to identify possible plant diseases and symptoms.
5. Weather Intelligence – Provides current weather conditions and short-term forecasts.
6. Multilingual AI Assistant – Supports farming-related queries in English, Telugu, Hindi, and Tamil.

🛠️ Technologies Used

- Frontend: React.js, Vite, JavaScript, HTML, CSS
- Backend: Python, FastAPI
- AI Integration: Google Gemini AI
- Weather API: Open-Meteo API
- Supporting Libraries: HTTPX, Python-dotenv, Python-multipart, Uvicorn

⚙️ Application Workflow

1. Farmer enters location, crop, soil details, or uploads a leaf image.
2. React frontend collects and sends the input to the FastAPI backend.
3. Backend validates the information.
4. The selected AI agent processes the request using Gemini AI and weather data where required.
5. The application displays findings, recommendations, and practical next steps.

🎯 Project Objectives

- Simplify agricultural decision-making.
- Provide AI-based farming recommendations.
- Support early identification of possible crop diseases.
- Improve irrigation planning.
- Provide accessible agricultural information in multiple languages.
- Integrate different farming support services into one platform.

🌟 Expected Benefits

- Faster access to farming guidance.
- Better-informed crop and soil management decisions.
- Improved awareness of possible crop diseases.
- Weather-based irrigation support.
- Easy access to multilingual agricultural assistance.

⚠️ Disclaimer

This application provides AI-generated agricultural decision support. It does not replace laboratory soil testing, professional agricultural advice, or expert disease diagnosis.
